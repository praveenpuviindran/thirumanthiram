# Audio Files

Place verse audio recordings here. Name them with this exact convention:

  thirumanthiram_XXXX.m4a   (XXXX = 4-digit verse number with leading zeros)

Examples:
  thirumanthiram_0001.m4a   → verse #1
  thirumanthiram_0081.m4a   → verse #81 (Anbe Sivam)
  thirumanthiram_3047.m4a   → verse #3047 (last verse)

Supported formats: .m4a, .mp4, .mp3, .aac, .wav

After adding files, update the audioUrl field in data/thirumanthiram.ts for those verses.
For local files use the asset path; for hosted files use the full https:// URL.
